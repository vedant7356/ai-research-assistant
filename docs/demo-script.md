# Demo Script (about 4-5 minutes)

Before recording: backend and frontend running, My Library empty or clean, `.env` filled in, `test-pdfs/ECE_50877_Project_Research_Plan.pdf` ready.

1. **Intro (10 s):** "ResearchMate AI: search, save, upload, summarize, ask." Show the status panel (Backend up, Database up).
2. **Search (40 s):** Discover page, search "retrieval augmented generation". Point out title, authors, year, abstract, link. Expand one abstract. Toggle the Open access filter.
3. **Save (30 s):** Save two papers. Open My Library, show them. Refresh the page (they stay). Optional: mention the backend restart test.
4. **Upload (60 s):** Upload page, drop the PDF. Show extracted title/authors/year/abstract and the "may be wrong" notice, correct one field, Save changes. Show it in My Library as "Uploaded PDF - Full text". Optionally try an image file to show it is rejected.
5. **Summarize (45 s):** On the uploaded paper press Summarize. Show the sections and the line "Written from the full paper text". Mention a saved search paper says "abstract only" when no full text exists.
6. **Ask (60 s):** Ask "Which libraries and compilers are being tested?" Open "Passages used". Then ask something not in the paper ("What was the accuracy on ImageNet?") and show "The paper text I have does not say."
7. **Close (10 s):** One sentence on the stack: React, Spring Boot, PostgreSQL, PDFBox, OpenAlex, Purdue GenAI Studio.
